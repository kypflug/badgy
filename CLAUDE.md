# Agent guide — Badgy

A **client-only, installable** attendance **calendar** for RTO/badge-in planning. Sign-in is **MSAL**
(Microsoft accounts); each user's data lives **privately in their own OneDrive app folder** via
Microsoft Graph, synced across devices with a **CRDT**. No backend, no operator-held data.

## First actions
1. `nvm use` (Node 24) then `npm install`.
2. `@rto/shared` builds before `web` typecheck.
3. Validate with `npm run gates` (lint + lint:css + typecheck + build + test).

## Layout
- `packages/shared` — **source of truth**: taxonomy (`types.ts`), BELT (`belt.ts`), date/calendar utils
  + holidays + meetup registry (`calendar.ts`), `compliance.ts` (rolling BELT, actual vs projected),
  `planner.ts`, and the **CRDT sync core** (`sync/hlc.ts`, `sync/doc.ts`). Heavily unit-tested.
- `packages/web` — Lit + esbuild SPA + PWA.
  - `auth/` — MSAL public client; `sync/` — Graph app-folder transport + dev mock.
  - `state/store.ts` — sync engine + calendar API over the doc (optimistic edits → debounced
    pull/merge/push; localStorage = offline cache).
  - `components/` — `rto-app` (shell), `month-calendar` (grid + click menu + **drag-select** range
    toolbar), `compliance-bar` (ring + planner), `settings-dialog` (usual week, target, meetup, theme,
    import, account).
  - `lib/` — status meta, theme (Light/Dark/System), format, xlsx import. `sw.ts` — service worker.
  - `public/` — manifest, icons (generated by `scripts/gen-icons.mjs`), `favicon.svg`.

## Data model (don't break)
- Sparse CRDT doc of **overrides**, keyed per ISO date (`d|YYYY-MM-DD`) + weekly pattern (`pat|<0-6>`)
  + meetup (`m|<Mon>`) + `cfg|targetBelt`. Unset days resolve from defaults: weekend→none,
  holiday→holiday, else `pattern[weekday] ?? office`. `merge` must stay commutative + idempotent;
  every write gets a fresh `hlc.tick()`. `migrate()` upgrades v1 weekly-grid docs.
- **Taxonomy:** office/remote/vacation/sick/holiday/travel/oof (+ `none`). Only `office` counts toward BELT.
- **BELT:** rolling best-8-of-12 ÷5; bands 80/90. Past=actual, future=forecast (today boundary).

## Conventions (mirror `theseus`)
TypeScript, ESM, `verbatimModuleSyntax` (`import type`). Lit for UI; Biome + stylelint; Playwright +
vitest. Style **only** with MAI tokens (`var(--smtc-…)`); large squircle radii; AI gradient reserved
for the brand mark / accents.

## Deploy
`MSAL_CLIENT_ID=<id> npm run build` → deploy `packages/web/dist` to **Azure Static Web Apps**
(`swa deploy`). Public client (PKCE, no secret), MSA + work/school, SPA redirect URIs = SWA host +
`http://localhost:5173`. See `docs/SETUP.md`.
